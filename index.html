Réseau · Wi-Fi domestique

Réseau domestique redéployé En production

Déploiement réel d'un point d'accès câblé (Livebox ZTE en mode AP : IP statique 192.168.11.250, DHCP désactivé, liaison filaire) pour étendre le Wi-Fi 5 GHz d'une maison, sans impacter les autres appareils. Durcissement : WPA3-SAE, DNS résolveur Cloudflare (1.1.1.1) sur le routeur, DNS-over-HTTPS sur le poste Windows. Diagnostic : double câble inutile entre les mêmes équipements (risque de boucle), projet routeur isolé abandonné après vérification des profils WAN.
